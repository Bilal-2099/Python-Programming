# Variables & Data Types

## 📌 Overview
This folder contains lessons and example code related to basic Python programming concepts — specifically **variables** and **data types**. These are foundational skills you’ll use in every Python project.

## 🧾 What’s Inside
- Demonstrations of how to declare variables (e.g., `x = 10`, `name = "Bilal"`)  
- Examples of different Python data types:
  - **Integers** (e.g., `5`)  
  - **Floats** (e.g., `5.7`)  
  - **Strings** (e.g., `"hello"`)  
  - **Booleans** (`True`, `False`)  
  - **Lists**, **Tuples**, **Dictionaries**, **Sets** (if included)  
- Sample scripts showing:
  - How values change when you assign new values to variables  
  - How Python handles different data types  
  - Type checking and casting (e.g., `int()`, `str()`)  

## 🎯 Learning Goals
By the end of working through this section you should be able to:
- Define and use variables in Python  
- Identify and pick appropriate data types for different values  
- Convert between data types when needed  
- Understand how Python stores and represents basic data  

## 🧑‍💻 How to Use
1. Open any of the `.py` example files in this folder.  
2. Read the comments/explanations at the top of each file to understand the context.  
3. Run the file in your terminal or editor to see the output. For example:  
   ```bash
