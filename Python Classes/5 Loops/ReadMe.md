# Practice 5: Loops

## 📌 Overview  
This Jupyter notebook (`Practice 5 Loops.ipynb`) focuses on **looping constructs in Python** — how to iterate over data, repeat tasks, and control flow with loops.

## 🧾 What’s Inside  
- Examples of `for` loops (iterating over lists, tuples, strings, dictionaries).  
- Examples of `while` loops (running until a condition becomes false).  
- Loop control tools: `break`, `continue`, `else` with loops.  
- Nested loops and combinations (loop inside another loop).  
- Practice exercises: e.g., iterate over data structures, build patterns, sum items, filter items.

## 🎯 Learning Goals  
By completing this notebook you should be able to:  
- Use `for` and `while` loops in Python with appropriate syntax.  
- Understand when to use one type of loop vs the other.  
- Use `break` and `continue` effectively to control the loop’s behavior.  
- Apply loops to real tasks like aggregation, filtering, pattern generation.  
- Read someone else’s loop and predict what it will print / how many iterations it will run.

## 🧑‍💻 How to Use  
1. Open the notebook in your Jupyter environment or VS Code.  
2. Run through each cell: read the explanation (if any), run the code, and observe the results.  
3. Modify the examples:  
   - Change the loop’s data (e.g., iterate over a different list).  
   - Replace a `for` with a `while` and compare behavior.  
   - Insert `break` or `continue` in new places and see effects.  
4. After finishing the built-in exercises, challenge yourself:  
   - Write a loop that prints out a multiplication table for a given number.  
   - Given a list of numbers, use a loop to filter out odd numbers into a new list.  
   - Use a nested loop to print a simple pattern (e.g., a right-angled star triangle).

## 🔍 Why This Matters  
Loops are essential for any meaningful programming:  
- They let you repeat tasks without writing the same lines again.  
- They’re the backbone of reading lists, processing datasets, generating patterns, automating tasks.  
- When you understand loops well, you’ll move smoothly into more advanced topics like comprehensions, generators, and algorithms.
