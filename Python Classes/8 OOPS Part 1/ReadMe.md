# Practice 8: OOPS Part 1

## 📌 Overview  
This Jupyter notebook (`Practice 8 OOPS Part 1.ipynb`) introduces you to Object-Oriented Programming (OOP) concepts in Python: how to define classes, create objects, and use methods and attributes.  
These are essential for writing structured, reusable, and scalable code.

## 🧾 What’s Inside  
- How to **define a class** using the `class` keyword, with attributes and methods.  
- How to **create objects** (instances) of a class and access their properties.  
- The concept of **`__init__`** (constructor) to initialize object state.  
- Use of **methods** and how they change object behaviour or state.  
- Possibly intro to class vs instance variables, simple inheritance (if included).  
- Practice exercises where you:
  - Define your own classes (e.g., `Car`, `Student`)  
  - Create objects, call methods, change attributes  
  - Extend classes or add new methods to deepen functionality  

## 🎯 Learning Goals  
By the end of this notebook you should be able to:
- Write a class in Python with attributes and methods.  
- Understand the difference between class variables and instance variables (if covered).  
- Instantiate objects and work with their state and behaviour.  
- Use constructors (`__init__`) to set up initial object state.  
- Recognize how OOP helps organize code when dealing with many related functions/data together.

## 🔍 Why This Matters  
Object-Oriented Programming is key for:
- Building larger applications (think web apps, games, data tools) where you group data + related functionality.  
- Making your code more readable, maintainable, and extendable — when you have many functions and related data.  
- Using frameworks and libraries that themselves rely on classes (for example in web frameworks or GUI toolkits).

## 📚 What Comes Next  
Once you’re comfortable with OOP basics, move on to:
- **Inheritance & Polymorphism** (classes inheriting from others, method overriding).  
- **Encapsulation & Abstraction** (control access to data inside objects).  
- **Modules & Packages** (organize many classes across files).  
- **Real-world projects using OOP** (building a simple class-based application or integrating with a framework).
