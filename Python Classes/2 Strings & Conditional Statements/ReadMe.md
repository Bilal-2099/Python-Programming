# Strings & Conditional Statements

## 📌 Overview  
This folder contains lessons and example code focused on two core Python topics: **strings** and **conditional logic**.  
These are foundational for any program that works with text input, branching logic, decision-making and basic user interactions.

## 🧾 What’s Inside  
- Examples of how to create and manipulate strings:
  - Single- and double-quoted strings  
  - Multi-line strings using triple quotes  
  - Accessing characters via indexes and slicing  
  - Common string methods (e.g., `len()`, `upper()`, `lower()`, `strip()`, `split()`)  
  - Checking membership (`in`, `not in`) and iteration over strings.

  - Comparison operators (`==`, `!=`, `>`, `<`, `>=`, `<=`)

  - Nested conditions and decision-making based on string or numeric input

## 🎯 Learning Goals  
By the end of working through this section you should be able to:
- Define and manipulate strings in Python  
- Use string operations to inspect, modify or combine text  
- Write correct conditional logic to split program flow based on data  
- Combine strings and conditions (e.g., checking if a substring exists, making decisions based on text content)  
- Read code that uses these concepts and predict its output
