# Practice 3: Lists & Tuples

## 📌 Overview  
This Jupyter notebook (`Practice 3 Lists & Tuples.ipynb`) contains exercises and examples focused on working with two core Python data structures: **lists** and **tuples**.  
These structures are fundamental for organizing, accessing, and processing sequences of data in your programs.

## 🧾 What’s Inside  
- Demonstrations of how to create lists and tuples.  
- Examples of basic operations such as indexing, slicing, iterating through elements.  
- How to modify lists (adding/removing elements) vs how tuples remain immutable.  
- Use cases for lists and tuples (e.g., storing multiple values, grouping data).  
- Practice problems that ask you to manipulate and analyze lists and tuples.

## 🎯 Learning Goals  
By the end of working through this notebook you should be able to:  
- Define and use lists and tuples in Python.  
- Understand the difference between mutable (list) and immutable (tuple) data types.  
- Use indexing, slicing, and iteration to access elements.  
- Perform operations such as appending or removing items in lists.  
- Recognize when a tuple might be a better choice than a list.

## 🧑‍💻 How to Use  
1. Open the notebook in Jupyter or VS Code.  
2. Work through each cell: read the explanation, then run the code to see how it behaves.  
3. Modify existing cells or add new ones:  
   - Try creating a list of your own values.  
   - Convert a list to a tuple (and vice-versa) and observe behavior.  
   - Write a small loop to iterate over a tuple and conditionally print elements.  
   - Experiment: replace a list with a tuple in a part of the notebook and observe what breaks (or doesn’t).  
4. After finishing the built-in exercises, challenge yourself:  
   - Given a list of numbers, use list methods to remove duplicates and then convert to a tuple.  
   - Given a tuple of strings, use list comprehension to create a new list with transformed values (e.g., uppercase versions).

## 🔍 Why This Matters  
Lists and tuples are everywhere in Python:  
- You’ll use them for storing user input, grouping items in APIs, managing data in loops.  
- Understanding mutability (changeable vs fixed) is vital for writing correct and efficient code.  
- These concepts prepare you for more advanced structures (dictionaries, sets) and workflows (data pipelines, algorithms).

## 📚 What Comes Next  
Once you feel comfortable with lists and tuples, the next topic is likely:  
- **Dictionaries & Sets** (key-value lookup, unique collections)  
- **Loops and Comprehensions** (to traverse and transform data)  
- **Functions** (to encapsulate your list/tuple logic into reusable code blocks)
